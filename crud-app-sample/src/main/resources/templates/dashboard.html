🚀 How to Add a New Secured CRUD Endpoint

1. Create a Model Create a class extending BaseEntity in the data packages.
2. Annotate Entity Add @Entity and @CrudResource(path="...", roles={"..."}).
3. Database Migration Add a Liquibase changeset to create the table structure in PostgreSQL.
4. Reload Dashboard Compile and boot. The new resource tab automatically renders with all parameters.
