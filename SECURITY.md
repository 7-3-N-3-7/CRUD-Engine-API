# Security Policy

## Supported Versions

We actively monitor and patch vulnerabilities in our core API engine. Please ensure you are running a supported version to keep your deployment secure.

| Version | Supported          | Notes |
| ------- | ------------------ | ----- |
| 1.0.x   | :white_check_mark: | Current Stable Release |
| < 1.0   | :x:                | Legacy / Development builds (Upgrade recommended) |

## Reporting a Vulnerability

We take the security of our CRUD Engine API seriously. If you discover a security vulnerability, we strongly encourage you to report it responsibly. **Please do not open a public GitHub issue for security vulnerabilities.**

### How to Report
To report a vulnerability, please use one of the following methods:
1. **GitHub Security Advisories (Preferred):** Go to the **Security** tab of this repository, select **Advisories**, and click **Report a vulnerability**. This keeps the disclosure private between you and the maintainers.
2. **Direct Contact:** Alternatively, you can open a confidential draft advisory or contact the maintainers directly if specific contact details are provided in your profile.

### What to Include
To help us triage and patch the issue quickly, please include:
* A detailed description of the vulnerability.
* Clear steps to reproduce the issue (or a proof-of-concept script).
* The potential impact of the exploit (e.g., unauthorized data modification, SQL injection, privilege escalation).

### Our Response Process
* **Acknowledgement:** You will receive an initial response acknowledging your report within 48 hours.
* **Triage & Patch:** We will investigate the issue and, if verified, work on a fix. We aim to release a patch for critical issues within 7 to 14 days.
* **Credit:** With your permission, we will gladly credit you for the discovery in our release notes and public security advisory.
